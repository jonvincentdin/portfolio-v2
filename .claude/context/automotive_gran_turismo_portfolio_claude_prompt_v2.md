# MASTER BUILD PROMPT — AUTOMOTIVE / GRAN TURISMO INSPIRED DEVELOPER PORTFOLIO

You are acting as a Senior Frontend Engineer, Senior UI/UX Designer, Creative Web Developer, Design Systems Engineer, Motion Designer, and Software Architect.

Your job is to design and build an exceptionally polished personal developer portfolio inspired by:
- premium automotive websites
- supercar configurators
- automotive specification pages
- Gran Turismo-style vehicle selection interfaces
- motorsport dashboards
- luxury automotive editorial design

I have provided visual references showing the general aesthetic I want.

IMPORTANT:
Do NOT copy the referenced websites directly. Create an ORIGINAL portfolio design from their visual principles.

The finished portfolio should feel like:

> "A developer portfolio designed as though every project were a high-performance automobile being unveiled in a premium digital showroom."

It must look extremely polished.

Not like a generic developer portfolio with some car images added on top.

# 1. PRIMARY EXPERIENCE

The portfolio should behave like a digital automotive showroom.

My projects are the "cars."

The Projects section should take inspiration from vehicle-selection systems in games such as Gran Turismo.

Imagine a project positioned inside a premium digital showroom.

The visitor can click:
